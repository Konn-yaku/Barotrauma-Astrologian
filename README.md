# Astrologian 占星术士(未完成)

《潜渊症》(Barotrauma) 的职业模组。加入一个以《最终幻想14》**占星术士**（Astrologian）为主题的治疗职业，
职业定位取自原版**医生**（Medical Doctor）。

> **开发中 (WIP)**

## 特点

- **治疗者定位** — 主技能为医疗，偏向艇内支援
- **纯 XML 实现** — 不需要 Lua / LuaCsForBarotrauma
- **中英双语**
- **所有天赋都能点满** — 共 20 个天赋，在默认等级上限（20 级）下刚好可以全部解锁

## 初级天赋

开局即可点选，共 8 个，分**两行**（每行点出 1 个即解锁下一行，每行最多可以全部点满）。

### 第 1 行

| 天赋 | 效果 |
|---|---|
| **星图** | 医疗物品价格 −10%；每回合生命值首次低于 30% 时获得 100 马克；**队友击杀敌人时你获得 5 点经验** |
| **星位合图** | 你治疗队友时，自己也缓缓恢复 |
| **袖内抽卡** | 每完成一次任务，你获得 **1 袋血袋** |
| **康复** | 你用**绷带**给队友施药时，一并清除目标的**流血与烧伤** |

### 第 2 行

| 天赋 | 效果 |
|---|---|
| **本轮** | 拖拽角色时移动不受限 |
| **星极** | 技能获取速度 +50%，**医疗技能 +30**；每治疗一名队友 +1 层，每层再 +5%，**最高 +100%（10 层）**（面板显示层数） |
| **重力** | **你自己**获得 30% 眩晕抗性（不容易被撞倒）；解锁「压力稳定器」配方 |
| **光速** | 潜艇上有人失去知觉时，你获得 40% 移动速度加成，且**你自己的心肺复苏效力 +100%**（把人从昏迷里救回来快一倍） |

## 占星魔法

| 层 | 天赋 | 效果 |
|---|---|---|
| 1 | **吉星相位** | 你对队友施药或治疗时，该队友获得 10 秒持续回复（伤势与出血缓缓消退）；目标生命值低于 30% 时，你的治疗效果提升至 **1.5 倍**；解锁「自动注射器耳机」配方 |
| 2 | **擢升** | 600 范围内有队友时，你受到的伤害 **−15%** |
| 3 | **阳星合相** | **600 范围内**的船员在**生命值低于 40%** 时持续回复**伤势**（0.2/秒）—— 高于 40% 不生效，定位是瀕死急救而非常驻治疗 |
| 4 | **中间学派** | **两相同存**：①「吉星相位」施药时额外给对方 **+20% 生命上限**（持续到巡回结束）；②「阳星合相」范围内获得 **+10% 生命上限 / +5% 移速** 的常驻光环 |

## 奥秘卡

**抽卡制**：抽出手牌，**在健康界面里把卡拖到某一名船员身上**，只给他一个人一段时间增益。

| 极 | 抽卡道具 | 卡池 |
|---|---|---|
| 星极 | **星极抽卡** | 太阳神之衡 · 放浪神之箭 · 建筑神之塔 |
| 灵极 | **灵极抽卡** | 战争神之枪 · 世界树之干 · 河流神之瓶 |
| 小奥秘卡 | *（第 3 档天赋解锁）* | 星极 → 王冠之领主（=**原版破片手榴弹**换皮）；灵极 → 王冠之贵妇（=**原版修复手雷**换皮）。**不占卡槽**：由天赋直接发到随身物品栏（卡槽为 3 格） |

**流程**

1. 点出第 1 档「**六天座**」→ 手上自动出现一本「星极抽卡」
2. **按住右键使用它** → 该极的 3 张卡装进它自己的容器（随身只占 1 格）
3. 把要用的卡拖出来 → 打开**健康界面**，把卡拖到某名船员的肢体上 → **只有那一个人获得 15 秒对应增益**，卡消失（没有"右键给自己上"这条路）
4. 抽卡书**生成后 60 秒**变成另一极的书（星极 ⇄ 灵极，循环）
5. 卡本身 60 秒失效 —— 正好在你下一次抽卡的时候
6. 抽卡书**自己接力**，所以天赋**只在一开始发这一本**；弄丢了可以花 **1 个塑料在制造台重做一本**

> ⚠️ **这些牌只认占星术士**：其他职业拿在手上会持续灼伤，根本不敢碰。

**天赋树**

| 档 | 天赋 | 效果 |
|---|---|---|
| 1 | **六天座** | 开启抽卡循环：发放一本「星极抽卡」；解锁配方「塑料 ×1 → 星极抽卡」。（卡的效果由卡自己施加 —— 只能在健康界面里拖给人，见上） |
| 2 | **抽卡** | 搜刮大型生物尸体时 20% 概率额外获得未研究基因材料；研究站与城市的商店开始出售基因材料；拆解物品时 20% 概率产出翻倍（基因材料与电路元件除外） |
| 3 | **小奥秘卡** | 抽卡时额外多一张王冠卡（**直接进背包，不占 3 格卡槽**）（**都是扔出去的**，不是打的）：星极 → 王冠之领主（**原版破片手榴弹换皮**）；灵极 → 王冠之贵妇（**原版修复手雷换皮，range 1000 / 修船 -200**） |
| 4 | **星力** | 一轮 3 张卡全部打出后，**只给自己** 20 秒增益：步行速度 +15%、游泳速度 +30%、远程攻速 +15% |

| 卡 | 效果（15 秒，单体） |
|---|---|
| **太阳神之衡** | 目标**近战攻速 +30% / 远程攻速 +10%** |
| **战争神之枪** | 目标**近战攻速 +15% / 远程攻速 +20%** |
| **放浪神之箭** | 目标**受到的治疗效果 +25%** |
| **世界树之干** | 目标**受到的伤害 −15%** |
| **建筑神之塔** | 目标维修速度与焊接船体速度 **+50%** |
| **河流神之瓶** | 目标**无需氧气**，并**持续治愈伤势**（15 秒约 22 点） |

> 减伤可以叠加：命运之轮 **10%** + 擢升 **15%** + 世界树之干 **15%** ⇒ 同类抗性最多到 **40%**。

## 会奶人的DPS

| 档 | 天赋 | 效果 |
|---|---|---|
| 1 | **天球仪** | 获得手持远程武器「天球仪」；**燃烧伤害 +25%**、对压载植物群伤害 **+50%**、自己受到的燃烧伤害 **−20%** |
| 2 | **命运之轮** | **蹲下蓄力 5 秒**后展开：你和 600 范围内的队友受到的伤害 −10%，起身后队友还保留约 5 秒 |
| 3 | **地星** | 获得「地星」，并解锁它的**制造配方与充能配方**（用完的地星 + 摄魂矿束） |
| 4 | **占卜** | 医疗技能 +45；自身伤害 +10%~+30%（随医疗技能阶梯）；**远程攻击时给 1000 内队友 +15% 伤害 / 20 秒，冷却 120 秒** |

### 天球仪

手持远程武器，发射即时光束，不需要弹药。可收进随身物品栏，要用时取出。

| 属性 | 值 |
|---|---|
| 类别 | 小型物品 |
| 持握 | 双手 |
| 射速 | 每 **2.5 秒**一发（其中蓄力 **1 秒**） |
| 弹药 | 不需要 |

| 项 | 天球仪 | 快速裂变加速器 |
|---|---|---|
| 结构伤害 | 20 | 35 |
| 物品伤害 | 20 | 35 |
| 主要伤害 | 20 | 50 |
| 穿甲 | 0.1 | 0.5 |
| 断肢概率 | 25% | 50% |
| 附加效果 | 焚灼（烧伤） | 辐射病 25 |

### 天球仪附带：焚灼

被动，不发放任何物品（点出「天球仪」即同时获得）：

| 项 | 值 |
|---|---|
| 造成的燃烧伤害 | **+25%** |
| 对压载植物群的伤害 | **+50%** |
| **自己受到的燃烧伤害** | **−20%** |

### 命运之轮

**蹲下并保持 5 秒**后展开，不发放任何物品：

| 项 | 值 |
|---|---|
| 生效范围 | **600**（**含自己**） |
| 受到的伤害 | **−10%** |
| 持续时间 | 蹲着就一直有；起身后队友再保留约 5 秒 |

### 地星

放在地上，需 10 秒蓄力。蓄力完成后，只要它所在的舱室开始进水，
就会释放一次范围 250 的船体修复，并把自身的星光（耐久）一次耗尽。

**耗尽后不会消失** —— 它只是熄灭了。带回去在制造台上用 **摄魂矿束** 就能重新点亮：

| 配方 | 材料 | 时间 / 技能 |
|---|---|---|
| **首次制造** | 固化泡沫手榴弹 + 水传感器 + 摄魂矿束 | 30 秒 / 医疗 **60** |
| **充能** | 用过的地星 + 摄魂矿束 | 15 秒 / 医疗 **50** |

## 安装

1. 将 `Astrologian` 文件夹放入游戏的 `LocalMods` 目录
   （通常为 `<Steam>/steamapps/common/Barotrauma/LocalMods/`）
2. 启动游戏 → **设置 → 模组** → 启用 `Astrologian`
3. 新建战役时即可在船员界面选择「占星术士」

> ⚠️ 本仓库**不含图片素材**，`Textures/` 已被 `.gitignore` 排除。
> 从仓库 clone 后需自备 `Textures/` 目录（结构与文件名见下），
> 否则职业图标、物品贴图与天赋/增益图标会显示为空。

> 修改任何文件后**必须完全重启游戏**才会生效。

```
   ├─ SimplifiedChinese/SimplifiedChinese.xml

```
