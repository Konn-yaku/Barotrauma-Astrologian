# Astrologian 占星术士

《潜渊症》(Barotrauma) 的职业模组。加入一个以《最终幻想14》**占星术士**（Astrologian）为主题的治疗职业，
定位与数值基线取自原版**医生**（Medical Doctor）。

> **开发中 (WIP)** — 三条专精线中已完成两条，其余内容见下方「完成度」表。

## 特点

- **治疗者定位** — 主技能为医疗，不擅长战斗，更偏向艇内支援
- **纯 XML 实现** — 不依赖 Lua / LuaCsForBarotrauma，无需任何脚本前置
- **中英双语** — 简体中文与英文文本齐全
- **原创天赋** — 不是原版天赋的换皮，每个天赋都按潜渊症真实的治疗逻辑设计
- **与「天赋增强」风格一致** — 专精不互斥、解锁门槛与其保持一致- **全队常驻增益** — 奥秘卡不做抽卡、不做随机目标，整局稳定生效，避免「需要战斗时抽到后勤卡」的错配

## 奥秘卡内容（第二栏）

6 张奥秘卡来自《最终幻想14》占星术士的抽卡系统，在这里改造为**被动、全队常驻**的团队增益。
每一档 = 1 张星极 + 1 张灵极，对应原作的两个抽卡按钮。

| 档 | 天赋 | 效果（基础 → 星力后） |
|---|---|---|
| 1 | **太阳神之衢** | 全队伤害 +15% → +20% |
| 1 | **战争神之枪** | 全队近战攻速 +20% / 远程攻速 +15% → +30% / +20% |
| 2 | **放浪神之箭** | 全队移速 +15% / 游泳速度 +20% → +20% / +30% |
| 2 | **世界树之干** | 全队伤害抗性 +15% → +20% |
| 3 | **建筑神之塔** | 全队维修速度（机械与电器）与焊接船体速度 +20% → +30% |
| 3 | **河流神之瓶** | 全队氧气消耗 −20% → −30% |
| 4 | **星力** | 你已点出的每张卡效果 **+50%** |

### 为什么不做抽卡

原版天赋**没有手动触发机制**（28 种 `abilityeffecttype` 全部是自动的），
抽卡只能靠定时随机。那样会出现「需要战斗时抽到后勤卡」的错配，
而且玩家人数有限，自然会只点最强的几张卡、在最强效果里循环。

改成**被动 + 全队常驻**之后：

- 没有随机性，卡的效果永远对得上场景
- 每一档的两张卡同属一类场景，选哪张都不是「错答案」
- **星力**把「选卡」变成「投资」——点的卡越多，放大收益越高

### 强度对照

每一项都**低于原版对应的天赋或基因数值**：

| 效果 | 本模组（星力后） | 原版参照 |
|---|---|---|
| 伤害 | +20% | 安全官 `implacable` +25%（限时·仅自己） |
| 攻速 | +30% / +20% | 舰长天赋 +30% / +20% |
| 移速 / 游泳 | +20% / +30% | 基因顶档 +25% / +50% |
| 伤害抗性 | +20% | 基因顶档 +25% |
| 维修 / 船壳 | +30% / +30% | 工程师 `stationengineer` +50% / +50% |
| 氧气消耗 | −30% | 基因 −20% ~ −100% |

> 需要说明的是，原版的增伤/攻速类天赋几乎都是**限时 + 仅自己**，
> 而本模组的卡是**整局永久 + 全队**，所以实际收益会明显高于单个原版天赋。
> 数值之所以敢取到上面这个水平，是因为每一项都卡在原版对应机制的下方。
## 设计说明

潜渊症**没有"回血"这个概念**。角色身上挂着各种状态（affliction），
医生的工作是**削减它们**——绷带只治出血、血袋只治失血、抗生素只治感染，用错药完全无效。

因此本模组的天赋不是"提高治疗量"，而是围绕这几件事设计：

- 让药物更有效、持续时间更长
- 减少药物消耗、自动处理状态
- 打断「出血 → 失血 → 伤害」这条连锁反应

## 安装

1. 将 `Astrologian` 文件夹放入游戏的 `LocalMods` 目录
   （通常为 `<Steam>/steamapps/common/Barotrauma/LocalMods/`）
2. 启动游戏 → **设置 → 模组** → 启用 `Astrologian`
3. 新建战役时即可在船员界面选择「占星术士」

> 修改任何文件后**必须完全重启游戏**才会生效——天赋树等定义只在启动时加载一次。
