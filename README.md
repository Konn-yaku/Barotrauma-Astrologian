# Astrologian 占星术士

《潜渊症》(Barotrauma) 的职业模组。加入一个以《最终幻想14》**占星术士**（Astrologian）为主题的治疗职业，
职业定位取自原版**医生**（Medical Doctor）。

> **开发中 (WIP)**

## 特点

- **治疗者定位** — 主技能为医疗，偏向艇内支援
- **纯 XML 实现** — 不需要 Lua / LuaCsForBarotrauma
- **中英双语**

## 初级天赋

开局即可点选，共 10 个，分**两行**（每行点出 1 个即解锁下一行，每行最多可以全部点满）。

### 第 1 行

| 天赋 | 效果 |
|---|---|
| **星图** | 医疗物品价格 −10%；每回合生命值首次低于 30% 时获得 100 马克；**队友击杀敌人时你获得 5 点经验** |
| **星位合图** | 你治疗队友时，自己也缓缓恢复 |
| **命运之轮** | 你和 600 范围内的队友受到的伤害 −10%（**本模组唯一一条通用减伤**） |
| **天星交错** | 你对队友施药时，该队友获得 8 秒「护盾」（生命上限 +30%） |
| **求生意志** | 为队友提供的心肺复苏效果 +20% |

### 第 2 行

| 天赋 | 效果 |
|---|---|
| **消防搬运** | 拖拽角色时移动不受限 |
| **星极** | 技能获取速度 +50%；每治疗一名队友 +1 层，每层再 +5%，最高 +150%（面板显示层数） |
| **重力** | 你和 600 范围内的队友获得 50% 眩晕抗性（不容易被撞倒）；解锁「压力稳定器」配方 |
| **生辰** | 有人失去知觉时，全队获得 75% 的出血/失血/缺氧/烧伤/辐射病/深层组织损伤抗性 |
| **凶星** | 你造成的伤害 +10% |

> 初级树已于 2026-09-15 完成去原版化：6 个天赋全部换成原创效果，且名字与效果对得上。
> 「星极」的层数计数器写法与第三栏「占卜」相同。

## 占星魔法

| 层 | 天赋 | 效果 |
|---|---|---|
| 1 | **吉星相位** | 你对队友施药或治疗时，该队友获得 10 秒持续回复（伤势与出血缓缓消退）；解锁「自动注射器耳机」配方 |
| 2 | **先天禀赋** | 目标生命值低于 30% 时，你的治疗效果提升至 2.2 倍 |
| 2 | **光速** | 潜艇上有人失去知觉时，你获得 40% 移动速度加成；拖拽其他角色时不再减速 |
| 3 | **阳星合相** | 你在潜艇内时，600 范围内的船员**生命值低于 20%** 时会被自动清除流血、烧伤与失血（高于 20% 不生效，定位是濒死急救而非常驻治疗） |
| 4 | **星天开门** | 进入任务时全船各获得一张庇护；各自**生命值低于 1%** 时自动触发，换来 **15 秒「不屈」**（不会昏迷 + 伤害 +25%），随后消耗 |

## 奥秘卡

**抽卡制**：抽出手牌，按需要打出去，给全队一段时间增益。

| 极 | 抽卡道具 | 卡池 |
|---|---|---|
| 星极 | **星极抽卡** | 太阳神之衡 · 放浪神之箭 · 建筑神之塔 |
| 灵极 | **灵极抽卡** | 战争神之枪 · 世界树之干 · 河流神之瓶 |
| 小奥秘卡 | *（第 3 档天赋解锁）* | 星极 → 王冠之领主（=**原版破片手榴弹**换皮）；灵极 → 王冠之贵妇（=**原版修复手雷**换皮）。**不占卡槽**：由天赋直接发到随身物品栏（卡槽为 3 格） |

**流程**

1. 点出第 1 档「**六天座**」→ 手上自动出现一本「星极抽卡」
2. **按住右键使用它** → 该极的 3 张卡装进它自己的容器（随身只占 1 格）
3. 把要用的卡拖出来，**按住右键打出** → **全队（含自己、无视距离）获得 15 秒对应增益**，卡消失
4. 抽卡书**生成后 60 秒**变成另一极的书（星极 ⇄ 灵极，循环）—— 和卡片自毁用的是**同一种计时器**（`Always` + `delay`），不依赖耐久、也不受进出站点/巡回影响
5. 卡本身 60 秒失效 —— 正好在你下一次抽卡的时候
6. 抽卡书**自己接力**，所以天赋**只在一开始发这一本**；弄丢了可以花 **1 个塑料在制造台重做一本**（不存在"进入站点 / 新巡回自动刷新牌堆"的机制，牌堆状态一路延续）

> ⚠️ **这些牌只认占星术士**：其他职业拿在手上会持续灼伤，根本不敢碰。

**天赋树**

| 档 | 天赋 | 效果 |
|---|---|---|
| 1 | **六天座** | 开启抽卡循环：发放一本「星极抽卡」；**并负责把卡的效果广播给全队（含自己、无视距离）**；解锁配方「塑料 ×1 → 星极抽卡」 |
| 2 | **重抽** | 拆解物品时 20% 概率产出翻倍（基因材料与电路元件除外） |
| 2 | **抽卡** | 搜刮大型生物尸体时 20% 概率额外获得未研究基因材料；研究站与城市的商店开始出售基因材料 |
| 3 | **小奥秘卡** | 抽卡时额外多一张王冠卡（**直接进背包，不占 3 格卡槽**）（**都是扔出去的**，不是打的）：星极 → 王冠之领主（**原版破片手榴弹换皮**）；灵极 → 王冠之贵妇（**原版修复手雷换皮，range 1000 / 修船 -200**） |
| 4 | **星力** | 一轮 3 张卡全部打出后，**只给自己** 20 秒增益：步行/游泳速度 +25%、近战攻速 +25%、远程攻速 +15% |

| 卡 | 效果（15 秒，全队） | 原版锚点 |
|---|---|---|
| **太阳神之衡** | 全队伤害 **+40%** | 原版最高 25% |
| **战争神之枪** | 全队近战攻速 **+50%** / 远程攻速 **+30%** | 原版上限 30% / 20% |
| **放浪神之箭** | 全队移速 **+35%** / 游泳速度 **+50%** | 基因 25% / 50% |
| **世界树之干** | 全队获得 **50% 眩晕抗性**，并**持续恢复**身体损伤、失血与流血（约 1.5 点/秒） | 战斗兴奋剂 45~50% |
| **建筑神之塔** | 全队维修速度与焊接船体速度 **+50%** | 工程师天赋 50% |
| **河流神之瓶** | 全队**无需氧气** | 压力稳定（同样的 100% 抗缺氧） |

> **为何不再有伤害减免**：世界树之干原本给的是 25% 全伤害抗性，现已改成「抗眩晕 + 持续愈合」
> （照搬原版医生「战斗兴奋剂」），本模组不再提供任何伤害减免。
>
> **数值基准**：每张卡只持续 15 秒（覆盖率 25%），属于短时爆发而非常驻，
> 因此统一按「原版对应锚点 × 1.5~1.6」定档。例：原版攻速天花板是 0.30 / 0.20，
> 本模组给到 0.50 / 0.30。

> ⚠️ **过渡状态**：
> 1. 6 张卡与星力均已定档（见上表）；
> 2. 两张王冠卡的效果是先落地再调的初版；
> 3. 占星魔法第 1/3/4 层（天星交错 / 阳星合相 / 星天开门）已重做，待实测。

## 会奶人的DPS

| 档 | 天赋 | 效果 |
|---|---|---|
| 1 | **天球仪** | 获得手持远程武器「天球仪」 |
| 2 | **焚灼** | 燃烧伤害 +25%；对压载植物群伤害 +50%；**自己受到的燃烧伤害 −50%** |
| 2 | **命运之轮** | 600 范围内队友：全部技能 +10、技能获取速度 +20%；自己武器技能 ≤50 时 −10 |
| 3 | **地星** | 获得「地星」，并解锁它的制造配方 |
| 4 | **占卜** | 医疗技能 +45；自身伤害 +10%~+30%（随医疗技能阶梯）；**每击杀一名敌人再 +1%（最多 +20%，天赋面板显示层数）**；附近队友 +10% 伤害 |

### 天球仪

手持远程武器，发射即时光束，不需要弹药。可收进随身物品栏，要用时取出。

| 属性 | 值 |
|---|---|
| 类别 | 小型物品 |
| 持握 | 双手 |
| 射速 | `reload 0.8` |
| 弹药 | 不需要 |

| 项 | 天球仪 | 快速裂变加速器 |
|---|---|---|
| 结构伤害 | 17 | 35 |
| 物品伤害 | 17 | 35 |
| 主要伤害 | 25 | 50 |
| 断肢概率 | 25% | 50% |
| 附加效果 | 焚灼（烧伤） | 辐射病 25 |

### 焚灼

被动，不发放任何物品：

| 项 | 值 |
|---|---|
| 造成的燃烧伤害 | **+25%** |
| 对压载植物群的伤害 | **+50%** |
| **自己受到的燃烧伤害** | **−50%** |

> 前两项照搬原版工程师「火焰狂人」，但**不包含**它的「解锁喷火器配方」那一项；
> 第三项是本模组加的（原版没有「燃烧抗性」这个属性）。
>
> 图标取自 FF14 的 `Combust` 系技能图标。

### 命运之轮

被动团队光环，不发放任何物品：**600 范围内**的队友（**不含自己**）持续获得

| 项 | 值 |
|---|---|
| 全部技能（电气 / 操舵 / 机械 / 医疗 / 武器） | **+10** |
| 技能获取速度 | **+20%** |

代价：占星术士本人**武器技能不高于 50** 时，自己的武器技能额外 **−10**。

> 机制照搬原版助手「摸鱼船员」，但把它的「修理速度 +25%」换成了技能获取速度 ——
> 修理速度已经由「建筑神之塔」那张卡占了。
>
> 旧版的「命运之轮」投掷装置（400 范围、65% 减伤 + 持续治疗）已撤下，目前无获取途径。

### 地星

放在地上，需 10 秒蓄力。蓄力完成后，只要它所在的舱室开始进水，
就会释放一次范围 250 的船体修复，随后消失。

一颗只能生效一次，要再用需在制造台重新制作（30 秒 + 1 精炼钍 + 2 塑胶）。

### 占卜

| 项 | 值 |
|---|---|
| 医疗技能 | +45 |
| 自身伤害 | 随医疗技能提升（见下表） |
| 自身伤害（击杀累积） | 每击杀一名敌人 +1%，最多 +20%（永久累积，死亡不清零；天赋面板显示层数进度条） |
| 队友伤害 | 1000 范围内 +10%，离开范围约 4 秒后失效 |

| 医疗技能 | < 40 | ≥ 40 | ≥ 60 | ≥ 80 | ≥ 100 |
|---|---|---|---|---|---|
| 伤害 | +10% | +15% | +20% | +25% | +30% |

> 击杀累积用的是纯 XML 的「计数器」写法（与工坊《东方额外职业-巫女》的「灵力」同构）：
> 一个 permanent stat 负责计数，同一个标识再挂一条带 `stattype` 的 `GivePermanentStat`
> 由引擎换算成 `层数 × 每层数值`，并用 `maxvalue` 封顶。

## 安装

1. 将 `Astrologian` 文件夹放入游戏的 `LocalMods` 目录
   （通常为 `<Steam>/steamapps/common/Barotrauma/LocalMods/`）
2. 启动游戏 → **设置 → 模组** → 启用 `Astrologian`
3. 新建战役时即可在船员界面选择「占星术士」

> ⚠️ 本仓库**不含图片素材**，`Textures/` 已被 `.gitignore` 排除。
> 从仓库 clone 后需自备 `Textures/` 目录（结构与文件名见下），
> 否则职业图标、物品贴图与天赋/增益图标会显示为空。

> 修改任何文件后**必须完全重启游戏**才会生效。
