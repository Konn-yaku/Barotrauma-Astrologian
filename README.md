# Astrologian 占星术士

《潜渊症》(Barotrauma) 的职业模组。加入一个以《最终幻想14》**占星术士**（Astrologian）为主题的治疗职业，
职业定位取自原版**医生**（Medical Doctor）。

> **开发中 (WIP)**

## 特点

- **治疗者定位** — 主技能为医疗，偏向艇内支援
- **纯 XML 实现** — 不需要 Lua / LuaCsForBarotrauma
- **中英双语**

## 初级天赋

开局即可点选，共 11 个。

| 天赋 | 效果 |
|---|---|
| **星图** | 医疗物品价格 −10%；每回合生命值首次低于 30% 时获得 100 马克 |
| **命理交织** | 你治疗队友时，自己也缓缓恢复 |
| **守护星** | 解锁「自动注射器耳机」配方 |
| **星轨测深** | 解锁「压力稳定器」配方 |
| **凶星** | 你造成的伤害 +10% |

其余 6 个为通用医疗兵天赋：最大生命 +20%、医疗道具效果 +20%、队友心肺复苏强化、心肺复苏效力提升、成瘾抗性 50%、拖拽时移动不受限。

## 占星魔法

| 层 | 天赋 | 效果 |
|---|---|---|
| 1 | **天星交错** | 医疗技能 +30；被治疗的队友获得 25% 全伤害抗性，持续整个任务 |
| 2 | **先天禀赋** | 目标生命值低于 30% 时，你的治疗效果提升至 2.2 倍 |
| 2 | **光速** | 潜艇上有人失去知觉时，你获得 30% 移动速度加成；心肺复苏效力提升 |
| 3 | **阳星合相** | 你在潜艇内时，1000 范围内的船员持续缓慢自愈（不断减轻伤害与出血） |
| 4 | **星天开门** | 进入任务时全船各获得一张庇护；各自倒地时自动触发，恢复满血后消耗 |

6 张卡，被动、全队常驻。

| 档 | 天赋 | 效果（基础 → 星力后） |
|---|---|---|
| 1 | **太阳神之衡** | 全队伤害 +25% → +35% |
| 1 | **战争神之枪** | 全队近战攻速 +30% / 远程攻速 +20% → +40% / +25% |
| 2 | **放浪神之箭** | 全队移速 +25% / 游泳速度 +35% → +35% / +45% |
| 2 | **世界树之干** | 全队伤害抗性 +25% → +35% |
| 3 | **建筑神之塔** | 全队维修速度（机械与电器）与焊接船体速度 +35% → +45% |
| 3 | **河流神之瓶** | 全队氧气消耗 −25% → −35% |
| 4 | **星力** | 你已点出的每张卡再强上一档 |

## 会奶人的DPS

| 档 | 天赋 | 效果 |
|---|---|---|
| 1 | **天球仪** | 获得手持远程武器「天球仪」 |
| 2 | **地星** | 获得「地星」，并解锁它的制造配方 |
| 3 | **命运之轮** | 获得「命运之轮」，并解锁它的制造配方 |
| 4 | **占卜** | 医疗技能 +45；自身伤害 +10%~+30%；附近队友 +10% 伤害 |

### 天球仪

手持远程武器，发射即时光束，不需要弹药。可收进随身物品栏，要用时取出。

| 属性 | 值 |
|---|---|
| 类别 | 小型物品 |
| 持握 | 双手 |
| 射速 | `reload 0.8` |
| 弹药 | 不需要 |

| 项 | 天球仪 | 快速裂变加速器 |
|---|---|---|
| 结构伤害 | 17 | 35 |
| 物品伤害 | 17 | 35 |
| 主要伤害 | 25 | 50 |
| 断肢概率 | 25% | 50% |
| 附加效果 | 焚灼（烧伤） | 辐射病 25 |

### 地星

放在地上，需 10 秒蓄力。蓄力完成后，只要它所在的舱室开始进水，
就会释放一次范围 250 的船体修复，随后消失。

一颗只能生效一次，要再用需在制造台重新制作（30 秒 + 1 精炼钍 + 2 塑胶）。

### 命运之轮

投掷物。落地即碎，为范围内所有角色提供 20 秒的 65% 全伤害抗性，
并持续减轻伤势与出血。

范围 400，不区分敌我。一次性消耗品。

### 占卜

| 项 | 值 |
|---|---|
| 医疗技能 | +45 |
| 自身伤害 | 随医疗技能提升（见下表） |
| 队友伤害 | 1000 范围内 +10%，离开范围约 4 秒后失效 |

| 医疗技能 | < 40 | ≥ 40 | ≥ 60 | ≥ 80 | ≥ 100 |
|---|---|---|---|---|---|
| 伤害 | +10% | +15% | +20% | +25% | +30% |

## 安装

1. 将 `Astrologian` 文件夹放入游戏的 `LocalMods` 目录
   （通常为 `<Steam>/steamapps/common/Barotrauma/LocalMods/`）
2. 启动游戏 → **设置 → 模组** → 启用 `Astrologian`
3. 新建战役时即可在船员界面选择「占星术士」

> 修改任何文件后**必须完全重启游戏**才会生效。
